# Animals_H

Animals_H 是一个面向宠物主题的前后端分离项目，包含首页展示、宠物介绍、社区聊天室、登录注册与消息实时通信等功能。前端采用 Vue 体系构建，部署到 Vercel；后端部署在腾讯云 Ubuntu 服务器上，并通过备案域名对外提供访问。

## 目录结构

- `frontend/`：前端项目，包含首页、社区页、登录弹窗、聊天室等模块
- `backend/`：后端项目，提供用户认证、聊天消息、首页数据等接口
- `docs/`：项目文档
- `tests/`：测试代码

## 项目特点

- 前端：Vue 页面组件化开发，支持响应式布局与交互优化
- 社区聊天室：WebSocket 实时通信、历史消息回显、时间分割展示
- 登录注册：公共弹窗组件复用，支持账号校验与状态管理
- 后端：NestJS 风格模块拆分，负责认证、聊天、数据库连接等能力
- 部署：前端部署于 Vercel，后端部署于腾讯云 Ubuntu，结合备案域名进行访问


## 说明

该项目适合作为个人作品集中的完整前后端实战案例，也可用于展示 Vue、WebSocket、NestJS、数据库与部署联调能力。
